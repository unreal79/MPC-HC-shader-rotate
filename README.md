# MPC-HC-shader-rotate
Shaders for MPC-HC video player: Rotate screen 90/180/270 degrees, while keeping the aspect ratio of the video.

## Usage
1. Save the files in "C:\Program Files (x86)\K-Lite Codec Pack\MPC-HC64\Shaders"
2. In MPC-HC: Right click: Shaders - Select Shaders... - Add to pre-resize (the file)
